# TechStore INACAP

#Sistema de administración de productos electrónicos hecho con Django.

## Pasos de ejecución
#1. Clonar el repositorio
#2. Crear entorno virtual: `python -m venv venv`
#3. Activarlo: `venv\Scripts\activate`
#4. Instalar dependencias: `pip install -r requirements.txt`
#5. Aplicar migraciones: `python manage.py migrate`
#6. Ejecutar el servidor: `python manage.py runserver`
#7. Abrir http://127.0.0.1:8000/
